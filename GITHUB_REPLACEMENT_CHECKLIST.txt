GITHUB PAGES DEPLOYMENT — IMPORTANT

1. Open the repository:
   https://github.com/shubhampandey11aug/my-portfolio

2. The contents of THIS ZIP must go directly into the repository root.
   Do NOT upload the enclosing ZIP/folder as a subfolder.

   Repository root must contain:
   index.html
   project.html
   project.js
   app.js
   data.js
   style.css
   .nojekyll
   assets/

3. Delete/replace the old website files:
   index.html, project.html, app.js, data.js, style.css
   and the old assets folder.

4. Make sure style.css is visible beside index.html in GitHub.
   If style.css is missing from the root, the page will look exactly like
   the unstyled screenshot (plain text/default browser links).

5. Keep the assets folder name exactly:
   assets

6. Picture rule:
   - Picture1 = homepage project card ONLY
   - Picture2 onward = case-study gallery
   - No Picture1 case-study hero/main image

7. After committing, wait for GitHub Pages to rebuild, then hard-refresh:
   Ctrl + F5

8. If the old page still appears, check:
   Settings -> Pages -> Source/Branch and confirm GitHub Pages is publishing
   the main branch from the repository root.

This package includes cache-busted CSS/JS references to avoid stale browser/CDN
assets after the replacement.
